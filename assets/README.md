# Profile artwork

The active profile artwork follows [Ritu Raj Prince’s About page](https://www.riturajprince.in/about), captured on November 10, 2026.

- `header.svg` uses the page’s portrait, DM Sans typography, charcoal background (`#0b0c0e`), cream text (`#f6f3f0`), and blue accent (`#0055fe`). The portrait is embedded so the SVG does not depend on an external image request.
- `footer.svg` uses the page’s closing copy and the same palette.
- Both SVGs use subtle CSS animation for the liquid-glass treatment, respect `prefers-reduced-motion`, and have a complete static appearance without animation. They contain no scripts or external resources.
- `work-tools.png`, `work-nevermiss.png`, `work-pdf.png`, and `work-image.png` reproduce the page’s project artwork. Project names, descriptions, and links remain readable Markdown/HTML in the main README.

The embedded DM Sans font is distributed under the [SIL Open Font License](DM-Sans-LICENSE.txt). Other SVGs in this directory are retained from the previous profile and are not used by the current README.

GitHub controls the README’s body typography, background, and layout. The page’s custom styling is reproduced within the artwork; navigation links, project links, and FAQ disclosures use GitHub-supported HTML.
